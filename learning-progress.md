# My Git Learning Progress

## Commands I practiced
- Checked repository state with `git status`.
- Reviewed changes with `git diff`.
- Staged files with `git add`.
- Saved changes with descriptive commits.
- Published commits and branches to GitHub.

## Workflow I am practicing
Feature branch → commit → push → Pull Request → review → merge → verify.

## What I learned
A commit saves a checkpoint locally. Pushing publishes it to GitHub. A Pull Request lets me review a change before merging it into `main`.
